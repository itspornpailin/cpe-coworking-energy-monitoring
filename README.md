# cpe-coworking-energy-monitoring
CPE Co-working Space energy monitoring web dashboard displays.

The system monitors environmental conditions such as illuminance (Lux) and
temperature, and provides data to a web-based 2D room monitoring dashboard.

## Tech Stack

### Backend
- Go
- Chi
- PostgreSQL
- pgx
- Goose

### Frontend
- React + TypeScript
- Planned

### IoT
- ESP32-based sensor nodes
- MQTT
- Planned
